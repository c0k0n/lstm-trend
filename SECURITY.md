# Security Policy

## Reporting a vulnerability

Please do not publish credentials, private data, or detailed exploit instructions in a public issue.

If GitHub offers private vulnerability reporting for this repository, please use it. Otherwise, contact `c0k0n` through [the GitHub profile](https://github.com/c0k0n) with the affected version, reproduction steps, possible impact, and safe supporting evidence.

This is an exploratory learning project and is not financial advice. Response and fixes are handled on a best-effort basis. Please allow time for investigation before making a report public.
